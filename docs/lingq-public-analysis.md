## 商业化结构

价格页展示美元：Premium 月付 14.99；年付 119.99；两年 215.76。Premium Plus 月付 29.99、年付 269.99。Plus 强调更多转写、AI 声音、聊天和简化课程。免费限制包括保存 20 个词句、导入 5 节内容、1 个播放列表。上述数字仅为分析记录，不自动成为本项目实际售卖价格。

推断：先让用户通过兴趣材料获得价值，再用可积累的词汇库、内容库与进度支持付费和续费。首页多个位置重复免费开始入口；学校、企业、图书馆入口扩展机构客户。

## 核心学习交互

官方公开指南描述：新词蓝色，保存后成为学习词（指南中为黄色），已知词不高亮；点击词查看释义并保存；词汇状态逐渐提升；保存的词跨课程出现；课程带听读和复习。指南可能滞后于当前登录内 UI，颜色不视为已验证的现行设计。

参考实现的数据模型：Lesson(id,title,level,topic,text,source)、Vocabulary(normalizedWord,meaning,status,context)、Progress(completedLessonIds,reviewCount)。必须在课程间共享词汇状态，并在浏览器刷新后保留。

## 本次实现边界与验收

在现有 Vue 3 项目新增独立 `/lingq-lab` 入口，用 X Learning 品牌和自编 AI/科技内容实现可体验的参考版本。保留既有首页与后端，不假装接入 LingQ 服务或真实付费。

1. 首屏借鉴公开页面的深蓝同心圆、内容主题节点、绿色 CTA；文案和图形使用本项目原创内容。
2. 可进入学习工作台：课程筛选/搜索、课程卡片、继续学习、学习统计。
3. 阅读器：点击英文词显示解释面板，可保存为学习词、标记已掌握；跨课程一致、localStorage 持久化。
4. 导入：支持标题与粘贴英文文本，验证空内容；URL 导入无后端时明确提示能力边界。
5. 复习：保存词汇生成卡片，翻面、认识/再学，状态与统计真实更新；空词库有返回学习入口。
6. 套餐展示仅为演示，无真实支付；禁止虚假注册、转写成功提示。
7. 桌面与移动布局、键盘可操作、构建通过。仅新增参考页面和必要路由，不覆盖用户未提交修改。

## 第四轮：真实网页链接导入

实际打开 LingQ 编辑器的 Web Links 来源：第二步提供文章/博客 URL 输入和 Review & Import。未在 LingQ 提交链接或创建课程。

本项目已接入 `POST /api/learning/web-import`，请求 `{ "url": "https://example.com/" }`，成功响应 `{ "title": "...", "text": "...", "sourceUrl": "..." }`；失败响应 `{ "error": "..." }` 和对应 HTTP 状态码。运行需要重启包含新代码的 Spring Boot 后端（8081），前端 Vite 通过现有 `/api` 代理访问。

- Jsoup 去除脚本、导航、页脚等，优先从 article/main 提取段落；仅返回文本，不执行页面脚本。
- 仅允许标准端口的公开 HTTP/HTTPS 网页，不传用户站点 Cookie 或登录凭据。解析所有 DNS 地址并验证，再为连接固定验证后的地址；每次跳转重新校验，最多跟随 3 次。
- 拦截本机、内网、链路本地及保留地址；最多读取 2 MB 解压后内容、正文 50,000 字符；连接和读取超时，单次请求有中止期限；并发提取上限 4。
- 前端提取后仍需检查、编辑并预览确认才写入浏览器课程。离开/切换来源会取消请求，忽略迟到响应；保留安全原网页链接。
- 不支持登录内容、PDF 或必须执行 JavaScript 才出现的正文；网站拒绝抓取、正文过短或过大时显示错误并允许粘贴文本。

验证：后端 4 项测试通过（URL/地址校验、正文清理、长度边界、API 契约）；前端请求处理与原数据迁移测试、构建通过；浏览器真实完成 example.com 提取→预览→课程阅读，确认本机地址提取被拒绝且未创建课程。本地联调后端使用临时 SQLite 数据库 `/tmp/xlearning-webimport-qa.db`，不操作项目已有业务数据库。
